  • ✓ Spatial-joins 2,752 OSM facility points against 243 ward polygons to get an actual facility count per ward
  • ✓ Engineers 8 geometric/spatial features per ward — area, compactness, solidity, distance from city center, local ward density
  • ✓ Compares Linear, Ridge, RandomForest & GradientBoosting via 5-fold CV instead of defaulting to the fanciest model
  • ✓ Explains every prediction with SHAP, so each flagged "desert" comes with a feature-by-feature reason

Building this was a real investigation. Here's what it took:

  • ✓ Pulled ward boundaries from DataMeet's community GitHub repo and facility points live from OpenStreetMap's Overpass API
  • ✓ Projected everything into UTM 43N to get accurate area, perimeter, and distance calculations — not raw lat/lon math
  • ✓ Tested 4 model families via 5-fold CV before picking one, instead of assuming the fanciest option would win

Why Ridge beat RandomForest & GradientBoosting

With only 243 wards and 8 features, the tree ensembles overfit.

RandomForest and GradientBoosting scored CV R² ≈ 0.08–0.11 with high variance across folds. Ridge regression (α=5.0) scored ≈ 0.13, more consistently — a concrete example of matching model complexity to dataset size instead of defaulting to the fanciest option.
